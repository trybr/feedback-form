# Форма обратной связи

Тестовое задание: форма обратной связи с валидацией на клиенте и сервере, отправкой письма через SMTP и защитой от ботов.

## Стек

- **PHP 8.x** — серверная часть, обработчик формы
- **PHPMailer 6.x** — отправка почты через SMTP
- **Vanilla JS (ES2015+)** — маска телефона, валидация, отправка через `fetch`
- **CSS** — без препроцессоров и фреймворков
- **GD** — генерация captcha
- **Сессии** — хранение CSRF-токена и кода captcha

Без jQuery, без React/Vue, без сборщиков. Всё работает «как есть».

## Требования

- PHP **7.4+** (проверено на 8.0–8.5)
- Расширения PHP: `mbstring`, `json`, `openssl`, `gd`, `session`
- Composer — для установки PHPMailer

## Установка (локально)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/trybr/feedback-form.git
cd feedback-form
```

### 2. Установить зависимости

```bash
composer install
```

После этого появится папка `vendor/` с PHPMailer.

### 3. Создать конфиг

Скопировать пример и заполнить своими данными:

```bash
cp inc/config.example.php inc/config.php
```

Открыть `inc/config.php` и указать:

| Параметр        | Что писать                                             |
| --------------- | ------------------------------------------------------ |
| `smtp.host`     | Хост SMTP-сервера, например `smtp.mail.ru`             |
| `smtp.port`     | `465` для SSL, `587` для TLS                           |
| `smtp.username` | Полный адрес почты, `user@mail.ru`                     |
| `smtp.password` | Пароль приложения (не обычный!)                        |
| `smtp.secure`   | `ssl` или `tls`                                        |
| `from`          | Адрес отправителя (совпадает с `username` для Mail.ru) |
| `to`            | Адрес получателя заявок                                |
| `subject`       | Тема письма                                            |

### 4. Запустить локальный сервер

```bash
php -S localhost:8080
```

### 5. Открыть в браузере

```
http://localhost:8080
```

Форма должна загрузиться, captcha — отрисоваться.

### 6. Проверить отправку

Заполнить форму, ввести верный код captcha, нажать «Отправить». Должно прийти письмо на адрес из `config.to`.

Если SMTP ещё не настроен — используй временную заглушку (см. раздел «Разработка без SMTP»).

## Разработка без SMTP

Если SMTP ещё не настроен, можно временно заменить отправку письма на запись в лог. Это позволит проверить всю остальную логику — валидацию, captcha, CSRF, honeypot, ajax.

В `inc/handler.php` найти блок с PHPMailer и заменить его на:

```php
file_put_contents(
    __DIR__ . '/../mail.log',
    "=== " . date('Y-m-d H:i:s') . " ===\n" . $body . "\n\n",
    FILE_APPEND
);

jsonOut([
    'success' => true,
    'message' => 'Сообщение отправлено (в лог).',
]);
```

После каждой отправки в корне проекта появится/обновится `mail.log` с данными формы.

Когда SMTP будет настроен — вернуть исходный блок с PHPMailer.
